# Android Root Module Collection

Repository ini berisi kumpulan module untuk Magisk dan KernelSU (KSU).

## ⚙️ Deskripsi

Project ini menyediakan beberapa module dan tools pendukung yang digunakan untuk:

- Root management
- System modification
- Integrity / Safety bypass
- LSPosed & addon support
- Busybox integration
- App management

Semua file di dalam repository ini diperuntukkan bagi pengguna yang memahami risiko modifikasi sistem Android.

## 📦 Isi Repository

Beberapa komponen yang tersedia:

- Magisk Module
- KernelSU (KSU) Module
- LSPosed
- Busybox
- Integrity Config
- App Manager
- Addon Module

## 🛠️ Persyaratan

Sebelum menggunakan module, pastikan:

- Bootloader sudah unlock
- Perangkat sudah terpasang Magisk atau KernelSU
- Memahami cara flashing module
- Backup sistem sebelum instalasi

## 📥 Cara Instalasi

### Untuk Magisk
1. Buka aplikasi Magisk
2. Masuk ke menu Modules
3. Pilih "Install from storage"
4. Pilih file module (.zip)
5. Reboot perangkat

### Untuk KernelSU
1. Buka aplikasi KernelSU
2. Masuk ke menu Modules
3. Install module dari penyimpanan
4. Reboot perangkat

## ⚠️ Disclaimer

Semua risiko akibat penggunaan module menjadi tanggung jawab pengguna. Modifikasi sistem dapat menyebabkan bootloop, error, atau kehilangan data.

Gunakan dengan bijak.
